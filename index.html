How to get your Yahoo OAuth Token

  1. Create a free app at Yahoo Developer Network (Select Web Application, Redirect URI: https://localhost:8080, Permissions: Fantasy Sports Read).
  2. Run the helper script in your project terminal: 
    python getYahooToken.py
  3. Enter your Client ID & Secret, authorize in your browser, and paste the generated access token above.

Note: Yahoo tokens expire after 1 hour. You can also use the Quick Paste Roster tab with zero tokens or setup!
